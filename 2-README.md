# Cinema seat booking (HashMap with a custom key)

A HashMap where the key is a `Seat` class, so `Seat` needs `equals()` and `hashCode()`.

- `Task_CinemaBooking.java` is the solution (Parts A to G, both methods)
- `ANSWERS.md` has the before/after behaviour and answers to Q1 to Q4 and the bonus

Run: `java Task_CinemaBooking.java` (or `javac` then `java Task_CinemaBooking`).
HashMap order may differ from run to run, as the task says.
